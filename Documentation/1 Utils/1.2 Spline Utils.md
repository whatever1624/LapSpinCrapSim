MUST HAVE HELPER FUNCTIONS FOR:
- Tangent
	- In the direction of travel
	- Use the spline derivatives
- Normal (lateral, on the xy plane)
	- Points to the left for right-hand rule compatibility with positive z up
	- Use the spline derivatives
- Trajectory angle (relative to the x axis, anti-clockwise)
	- Use the spline derivatives
- Lateral curvature
	- Curvature in the xy plane
	- Use the spline derivatives
- Vertical curvature
	- Instead of the curvature in the xy plane, think this needs to be the curvature in the tangent-z plane
	- Use the spline derivatives
	- Raise a ValueError if the spline is not 3D
- Parameterisation of coordinates based on a reference spline, for closest point
	- Objective function:
		- Minimise distance (vector norm) between the reference spline and the coordinate
	- Input:
		- Coordinate array (xy only)
		- Reference spline
	- Returns:
		- 1D float array where each element is the spline parameter for the corresponding coordinate
- Parameterisation of coordinates based on a reference spline, for trajectory normal
	- Objective function:
		- Root finding of the dot product between the reference spline tangent vector and the vector from the reference spline to the coordinate
		- This parameterisation may be sensitive to the smoothness of the reference spline, so maybe seed the root finding with the closest point parameterisation
	- Input:
		- Coordinate array (xy only)
		- Reference spline
	- Returns:
		- 1D float array where each element is the spline parameter for the corresponding coordinate
